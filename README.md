## 📖 Overview

Welcome to the source code of my personal portfolio. Designed with a philosophy of "quiet luxury" in code, this portfolio focuses on performance, scalability, and an elegant digital experience. It features a custom Single Page Application (SPA) architecture built with pure Vanilla JavaScript and styled using Tailwind CSS for a monochrome, modern aesthetic.

<br/>

## ✨ Key Features

- **🖤 Monochrome Aesthetic**: A sleek, dark-themed UI that focuses on readability and minimalism.
- **⚡ Custom SPA Router**: Blazing fast navigation between sections without page reloads.
- **📊 GitHub Contributions API**: Live integration displaying GitHub commit activity seamlessly.
- **🎵 Spotify "Now Playing" Widget**: Real-time Spotify integration showing current playback status and progress.
- **📱 Fully Responsive**: Built with modern CSS container queries and Tailwind utility classes for flawless display on all devices.
- **🚀 Performance Optimized**: Lightweight, vanilla JS implementation ensuring fast load times.

## 🚀 Getting Started

If you want to run this project locally to explore the code or make modifications, follow these simple steps:

### Prerequisites

You just need a modern web browser and a local HTTP server to run the project (due to ES modules and CORS policies).

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/PIXELoverHERE/Portfolio-Web.git
   cd Portfolio-Web
   ```

2. **Serve locally**
   You can use any local server, such as Python's built-in `http.server` or Node's `serve`.

   *Using Python:*
   ```bash
   python -m http.server 5500
   ```
   *Using Node/npx:*
   ```bash
   npx serve .
   ```

3. **Open in browser**
   Navigate to `http://localhost:5500` to view the portfolio.

> **Note on Spotify Widget:** To enable the live Spotify widget locally, you will need to set up a Spotify Developer App and follow the on-screen setup modal instructions by passing `?spotify-setup=true` in the URL.
